# Employee Payroll Management System

A web-based Employee Payroll Management System developed using Java, Spring Boot, MySQL, HTML, CSS and JavaScript.

## Project Overview

The Employee Payroll Management System is designed to simplify employee management, attendance tracking and payroll calculation through a centralized web application.

The system provides a login page and dashboard through which authorized users can manage employee details, attendance, payroll and salary information.

## Key Features

- Secure login system
- Employee management
- Add and update employee details
- Attendance management
- Payroll calculation
- Salary details and calculation
- Allowances and deductions management
- Dashboard for easy navigation
- MySQL database integration
- REST API based backend
- Responsive and simple user interface

## Project Modules

### 1. Login Management
Provides user authentication before accessing the system.

### 2. Employee Management
Allows users to view, add and update employee information such as name, department and salary.

### 3. Attendance Management
Records employee attendance with employee ID, date and attendance status.

### 4. Payroll Management
Calculates payroll using basic salary, allowances and deductions.

### 5. Salary Details
Displays salary information including basic salary, allowances, deductions and net salary.
