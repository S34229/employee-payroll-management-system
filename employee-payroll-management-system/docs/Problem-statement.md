# Problem Statement

## Employee Payroll Management System

### Existing Problem

Managing employee details and salary information manually is time-consuming and may lead to errors. Maintaining employee records using manual files or spreadsheets makes it difficult to search, update and manage payroll information efficiently.

### Proposed Solution

The Employee Payroll Management System is developed to digitally manage employee information and salary details in a centralized system. The system allows authorized users to add, view and update employee records such as employee name, department and salary.

The application is developed using Java and Spring Boot, with MySQL used as the database for storing employee information. REST APIs are used to perform operations on employee records.

### Objective

The main objective of this project is to reduce manual work, improve data accuracy and provide an efficient and organized way to manage employee payroll information.
